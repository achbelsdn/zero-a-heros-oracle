Créer une fonction

Un nom, des paramètres, un RETURN, un seul nombre.

FUNCTIONRETURNSELECT INTO

Recette

La fonction des sujets « nombre de… »

À chaque fois

  1. 1CREATE OR REPLACE FUNCTION nom_du_sujet
  2. 2Paramètre IN, typé avec %TYPE si tu connais la colonne.
  3. 3RETURN NUMBER juste après la parenthèse fermante, avant IS.
  4. 4Variable locale pour le COUNT.
  5. 5SELECT COUNT(*) INTO variable FROM … WHERE …
  6. 6RETURN variable; puis END;

Qui retourne une valeur scalaire ?

La fonction. Une procédure ne RETURN pas de valeur (elle peut avoir un paramètre OUT, mais le QCM attend « fonction »). Un trigger ne se rappelle pas pour obtenir un nombre. Un package est un conteneur, pas une valeur.
