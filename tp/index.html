Réponses qui ne sont pas du code

  • Question 1.2

    Le message sort dans DBMS Output. Sans SET SERVEROUTPUT ON, le bloc réussit mais rien ne s’affiche.

  • Question 2.2 b

    Sans EXCEPTION : ORA-01403 (no data found). SELECT INTO exige exactement une ligne.

  • Question 3.3

    Sans NVL, le client 99999 renverrait NULL. SUM sur zéro ligne ne vaut pas 0.

  • Question 4.2

    Pas de COMMIT dans la procédure : l’appelant valide. Le script se termine par COMMIT, ce qui rend les essais définitifs.

  • Question 5.2

    a et b échouent (ORA-20030). c réussit : UPDATE stock ne met pas prix dans le SET, donc UPDATE OF prix ne part pas.

  • Question 5.4

    Avec le trigger : ORA-20032. Sans lui : ORA-02292, la clé étrangère (child record found).
